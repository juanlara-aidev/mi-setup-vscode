================================================================
  MI SETUP DE VS CODE — Instrucciones de instalación
================================================================

PASO 1. INSTALAR LAS EXTENSIONES
--------------------------------------------------------------
En VS Code abre la pestaña de extensiones (Cmd+Shift+X en Mac /
Ctrl+Shift+X en Windows) y busca e instala:

  - Darker+                (autor: borekb)
  - Symbols                (autor: Miguel Solorio)
  - Claude Code            (autor: Anthropic)
  - GitHub Copilot
  - GitHub Copilot Chat


PASO 2. APLICAR LA CONFIGURACIÓN CON UN COMANDO
--------------------------------------------------------------
Abre tu terminal (NO importa en qué carpeta estés, funciona
desde cualquier ubicación). Copia y pega el comando completo
según tu sistema:


  ► macOS — abre "Terminal" o "iTerm" y pega esta línea:

mkdir -p "$HOME/Library/Application Support/Code/User" && curl -fsSL https://raw.githubusercontent.com/juanlara-aidev/mi-setup-vscode/main/settings.json -o "$HOME/Library/Application Support/Code/User/settings.json"


  ► Windows — abre "Windows PowerShell" y pega esta línea:

$d="$env:APPDATA\Code\User"; New-Item -ItemType Directory -Path $d -Force | Out-Null; $ProgressPreference='SilentlyContinue'; Invoke-WebRequest -Uri "https://raw.githubusercontent.com/juanlara-aidev/mi-setup-vscode/main/settings.json" -OutFile "$d\settings.json"


PASO 3. RECARGAR LA VENTANA DE VS CODE
--------------------------------------------------------------
Cmd/Ctrl + Shift + P → escribe "Reload Window" → Enter

Si el tema no se aplica solo:
  Cmd/Ctrl + Shift + P → escribe "Color Theme" → elige "Darker+"
